# Torres_CafeSysstem

## Project Description
The Campus Cafe Ordering System is a Java-based application that manages cafe orders. It allows customers to order beverages, pastries, and meals.

## Features
- Supports beverages, pastries, and meals.
- Calculates item prices.
- Applies student discounts.
- Supports voucher discounts.
- Calculates loyalty points.
- Limits each order to three items.
- Displays customer receipts.
- Validates invalid inputs.

## Java Classes
1. `MenuItem.java` – Abstract parent class for menu items.
2. `Beverage.java` – Handles beverage orders and sizes.
3. `Pastry.java` – Handles pastry orders and heating options.
4. `Meal.java` – Handles meal combos and extra sides.
5. `Customer.java` – Stores customer information and loyalty points.
6. `Order.java` – Manages orders, discounts, and receipts.
7. `CafeApp.java` – Main program used to run the system.

## How to Run
1. Open the project in IntelliJ IDEA.
2. Open `CafeApp.java`.
3. Click the green Run button beside the `main()` method.

## Requirements
- Java Development Kit (JDK)
- IntelliJ IDEA
